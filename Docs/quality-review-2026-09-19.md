# Ice 质量复查 · 2026-09-19

## 0.12.1 整改结果

下文原始审计表中的八项 P1/P2 工作已在本版实现：

- 公开静态更新源与 Release 下载地址，不再读取或发送 GitHub 令牌；兼容旧版迁移，文档说明 API 限流时需手动安装一次。
- 统一普通、Option、Control 和右键判定；点击时保存修饰键，保留托管菜单栏兼容入口和去重。
- 原生隐藏请求成功后才交接旧状态；增加超时、失败重试、取消和过期回调防护。临时显示等待真实完成，使用 Advanced 的时间设置，并在菜单窗口仍存在时延后收回。
- 暂停与恢复隐藏保留分区、排序和间距；真正重置作为独立确认操作。
- 运行期间低频检查权限，撤权时释放限制，重新授权后恢复；点击失败提供重试和打开应用入口。
- Ice Bar 原生焦点、方向键、Return／空格、Escape；搜索立即展示、异步刷新，补全按钮语义与无结果提示。
- macOS 27 完整 AX 枚举移到串行后台，合并请求并设时间预算；轮转扫描防止后面的应用饥饿，保留未扫描或暂时无响应应用的缓存，退出应用及时移除。
- 默认开发分支运行四组逻辑测试、发布脚本测试与未签名 Debug 构建；发布清单冲突/临时错误重试，每次写入重新校验远端版本，防止旧版覆盖新版。

## 本轮已修复

搜索项目原来用 `MenuBarItemInfo`（所属应用和名称）作为列表及选中项身份。同一应用的同名/空标题图标会共用身份，回车还会取第一个匹配项。现在列表和选中项解析统一使用 `stableID`；搜索文字、模糊匹配、顺序和动作不变。

位置：`Ice/MenuBar/Search/MenuBarSearchPanel.swift`，`ItemID`、`updateDisplayedItems`、`menuBarItem(for:)`。

| P1 | 无损暂停隐藏与真正重置分开 | “Show All Hidden Items” 实际调用 `resetModifications`，会清空已保存分区并重置全局间距。临时找图标不应等价于丢失布局；建议增加“暂停隐藏/恢复隐藏”，把重置布局保留为明确独立操作。 | 中 |
| P2 | 异常恢复与反馈 | pending assertion 无超时，若私有 API 不回调，后续刷新会一直被 pending 状态阻挡；这是代码层面的防护缺口，未注入故障复现。点击/重新获取失败目前只写日志，应提供重试或打开应用入口。权限轮询在启动设置完成后停止，运行中撤权需要独立的恢复路径。 | 中 |

| P2 | 枚举性能与即时显示 | 五秒枚举会在主线程遍历运行应用的 AX 接口；卡住的应用可累计阻塞。搜索在显示窗口前等待图像缓存更新。建议后台串行枚举、超时预算、事件驱动增量刷新，以及先显示搜索再刷新图标。 | 中至大 |

## 实测与证据边界

- 15 次、间隔约一秒的短时 `ps` 采样：平均 CPU 1.49%，最高 5.9%，末次 RSS 120.9 MiB。采样期间设置窗口/桌面环境并未严格隔离，不能当作长期空闲功耗或与早先样本的性能对比。
- 五秒调用栈采样中主线程大部分时间在等待事件；同时明确捕获 `cacheHostedItems → enumerateUncached → AXUIElementCopyAttributeValue` 在主线程执行。当前未见持续高占用，但还存在卡顿风险。
- 仓库 API 确认默认分支为 `codex/macos27-compat`、公开；本次未更改这两项设置。
- GitHub v0.12.0、更新清单和 build 1125 一致；发布工作流最终成功。新修复目前在开发分支/本机，不能把 Release 下载包当作最新源码构建。
- 本轮搜索修复的 Release 构建和应用签名验证通过；本机已安装。真实同名多项目应用的回归仍需专门 fixture，本轮通过代码确认身份冲突已移除；原生自动化访问菜单栏搜索入口时返回元素离屏，未完成搜索窗口交互验收，不能记为通过。
- 多屏热插拔、睡眠唤醒、全屏/Spaces 组合、权限撤销，以及私有 API 失败/不回调都还需要专项验收，不能由现有三轮正常交接测试替代。

## 功能迭代建议

上述交互与恢复完善后，先做配置备份/导入导出，再做工作/会议等命名布局及条件切换。完整中文设置与统一文案也是收益明确的小版本工作。Widgets、剪贴板历史等扩展暂排后面，避免扩大权限和维护面而拖慢菜单栏核心功能的成熟。
