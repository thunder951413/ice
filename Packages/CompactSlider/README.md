# CompactSlider

This is CompactSlider 1.1.6, vendored from <https://github.com/buh/CompactSlider>
at `abe4d1df6f0c85dcb133266cc07c2a5d08295726`.

It preserves the API used by Ice and wraps the `LinearGradient` in
`ProminentCompactSliderStyle` with `AnyView` so Xcode 27 resolves its `opacity`
modifier as `View.opacity`.
